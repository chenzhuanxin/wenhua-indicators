## 使用与注意事项

1. **导入方法**：文华财经（WH6/WH7）→ 公式管理器 → 导入，选择对应 `.XTRD` 文件。
2. **原文排版缺陷**：原公众号源码存在复制粘贴导致的运算符丢失（乘号 `*` 缺失，如  
   `20HHJSJDA`、`3K-2D`、`RCCKK`）与杂散 `?` 字符，本库在整理时已按语义修复为  
   `20*HHJSJDA`、`3*K-2*D` 等。
3. **合约参数表**：`量价`、`高低阈赢益决策`、`远近高低阈` 原文含 80 个品种的  
   峰值/谷值/均值参数表。为控制文件体积与可读性，本库版本**示范保留 10 个主力品种**  
   （螺纹钢、铁矿石、沪铜、沪金、原油、豆粕、棕榈油、白糖、PTA、甲醇）。  
   如需全品种，可按同样格式在 `峰值VA` / `谷值VA` / `均值VA` 中继续追加  
   `IF(ISCONTRACT('品种名')=1,数值,0)+` 项。
4. **跨合约引用**：`近远月合约指数强弱` 中的 `"9955$CLOSE"` / `"9956$CLOSE"`  
   为示例指数代码，请按实际合约替换。
5. **重复指标**：部分指标在原文多篇文章中重复出现（如 三指标共振≈三脉共振、  
   经典指标即刻买卖≈智诚、主图MACD指标≈主图MACD），已按名称分文件保留，便于对照。
